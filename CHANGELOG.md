# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-11-07

### Added
- Initial release of Minima CSS Framework
- Complete utility-first CSS classes similar to Tailwind
- Responsive breakpoints (sm, md, lg, xl)
- Dark mode support (automatic and manual)
- Pre-built components:
  - Buttons (multiple variants and sizes)
  - Form inputs (input, select, textarea, checkbox, radio)
  - Cards (with header, body, footer)
  - Alerts (multiple color variants)
  - Badges (multiple color variants)
  - Navbar
  - Container
- Comprehensive color palette with CSS variables
- Spacing utilities (margin, padding, gap)
- Layout utilities (flexbox, grid, positioning)
- Typography utilities
- Border utilities
- Shadow and opacity utilities
- Transition and transform utilities
- Documentation and demo page

### Notes
- Framework size: ~10.6KB gzipped (96.5% smaller than Tailwind)
- No build step required - just include the CSS file
- Fully customizable via CSS variables
- Mobile-first responsive design
