Features

Lightweight

Only ~10.6KB gzipped vs Tailwind's ~300KB+ - 96.5% smaller!

No Build Step

Just add the CSS file - no npm, no config, no purging required

Mobile-First

Responsive utilities (sm:, md:, lg:, xl:) just like Tailwind

Customizable

CSS variables make it easy to override colors and spacing

Familiar Syntax

Same class naming conventions as Tailwind CSS

Dark Mode

Built-in dark mode support with .dark class or prefers-color-scheme

Get Started

Direct Download

Download the CSS file directly:

Download minima.css Download minima.min.css

CDN (via jsDelivr)

Use the CDN for quick prototyping:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/MML9Code/minima@latest/minima.min.css">

Customization

Override Colors

Override the default colors using CSS variables:

:root {
  --color-primary: #3b82f6;
  --color-secondary: #6b7280;
  --color-success: #10b981;
  --color-danger: #ef4444;
  /* ... etc */
}

Dark Mode

Enable dark mode by adding the .dark class to your html element or using prefers-color-scheme:

<html class="dark">
  ...
</html>

// Or automatically with media query
@media (prefers-color-scheme: dark) {
  // Dark mode styles are automatically applied
}
